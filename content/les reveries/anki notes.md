could use this system 
```python
# Flags - for temporary workflow
flag_red = "needs_urgent_review"
flag_blue = "research_needed" 
flag_green = "easy_cards"

# Marks - for permanent organization
marked = "important_high_yield"
marked = "needs_edit_before_next_review"
marked = "suspend_but_keep_visible"
```

Flags
-> can track difficulty levels
-> temporary categorisation
- flag red: urgent review
- flag blue: research needed
- flag green: easy / low priority cards

Marks
-> binary categorisation
-> single state, more permanent, cleaner 
- important 
- need editing 
- easy to find
- come back later
